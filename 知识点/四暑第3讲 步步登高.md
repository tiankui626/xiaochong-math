# 四暑第3讲 步步登高

## 核心知识点

### 1. 等差数列基本公式

> [!tip] 核心公式
> - 通项公式：aₙ = a₁ + (n-1)d
> - 求和公式：Sₙ = (a₁ + aₙ) × n ÷ 2 = n × a中间项
> - 项数公式：n = (aₙ - a₁) ÷ d + 1

### 2. 中间项性质

> [!tip] 奇数项等差数列
> 奇数项的等差数列：中间项 = 平均数 = 和 ÷ 项数
> - 前5项和 = 5 × 第3项
> - 前7项和 = 7 × 第4项

### 3. 二阶等差数列

> [!tip] 定义
> 一阶差为等差数列的数列。如：3, 4, 6, 9, 13, 18, 24, 31, …
> 一阶差：1, 2, 3, 4, 5, 6, 7, …
> 通项：aₙ = a₁ + (1 + 2 + 3 + ⋯ + (n-1))

### 4. 缺项数列求和

> [!tip] 三种方法
> ① **拆分法**：拆成两个等差数列分别求和
> ② **补项法**：补全后减去缺少的项
> ③ **分组法**：按周期分组

### 5. 连续奇数之和

> [!tip] 公式
> 连续奇数之和 = n² - m²（从第m+1个奇数到第n个奇数）
> n个连续奇数的平均数 × n = 和

## 典型题型

1. **等差数列求和**：利用中间项性质快速求
2. **二阶等差数列求第n项**：累加一阶差
3. **缺项求和**：拆分或补项
4. **连续奇数分解**：n²-m²因式分解确定最多项数
5. **规律算式**：找被减数和减数各自的变化规律
